# Patag DayCare System

### Capstone Database Design

The Patag DayCare System is a capstone database project for a proposed daycare enrollment, child monitoring, and e-learning management platform. This repository focuses on the design and development of the MySQL database that will support the system.

## Project Overview

The database is designed to organize and manage daycare-related records, including guardian accounts, student information, enrollment applications, attendance, learning activities, and child evaluations.

The project emphasizes relational database design, data integrity, normalization, and structured data management.

## Database Features

- User accounts and role management
- Guardian and student records
- Enrollment applications and requirements
- Enrollment document tracking
- Class levels, sections, and schedules
- Student attendance records
- Lesson plans and learning materials
- Quizzes and assessment results
- Feeding records
- Child performance evaluations

## Database Technology

- **Database Management System:** MySQL
- **Database Design:** Relational database
- **Normalization:** Third Normal Form (3NF)
